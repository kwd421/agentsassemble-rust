# UI 전수 점검 목록

기준: 디스코드 실측값(메모리 ui-parity-workflow) + Fable 비평. 각 항목은 캡처 → 숫자 대조 → 수정 → 재캡처 → Fable 확인 순서.
표시: ✅ 완료(대조·수정·확인) · 🔶 캡처/수정했지만 Fable 확인 전 · ⬜ 아직 안 봄

## 시작·로그인
- ✅ 첫 화면(로그인 선택) — 정상 / 시작 실패 오류 / 버튼 비활성
- 🔶 첫 화면 — 게스트 이름 입력 단계 (안쪽 상자 제거, 폼 규격 통일)
- 🔶 첫 화면 — 복구 코드 입력 단계
- 🔶 첫 화면 — 복구 코드 보관 안내 단계(문구·경고 스타일)
- 🔶 첫 화면 — 서버 목록: 내 서버·다른 컴퓨터·꺼짐 캡처, '은퇴' 문구 교체 / 중복 서버 선택 캡처 ⬜
- ⬜ Google 가입 선택 (GoogleRegistrationChoice)
- ⬜ 로그인 서버 미설정 시작 화면("어떻게 사용할까요?")
- 🔶 브라우저 저장소 오류 화면 (원문 오류 제거)
- ⬜ 원격 소유자 연결 대기 (CentralOwnerConnectGate / Boundary)
- ⬜ 앱 업데이트 표시 (AppUpdateIndicator / FrontendUpdateNotice)

## 입장(웹 참가)
- 🔶 참가 동의 / 숨김 해제 동의 / 방 선택 / 로그인 / 오류 / 게스트
- ⬜ 회원 로그인 팝업 (MemberLoginPopup)
- ⬜ 로컬 참가자 패널 (LocalAttendeePanel)

## 메인 레이아웃
- ⬜ 서버 레일(방 아이콘, 친구 버튼, 추가 버튼, 알림 점, 우클릭 메뉴)
- ⬜ 채널 사이드바(헤더, 카테고리, 채널 행, 채널 우클릭 메뉴)
- 🔶 사용자 패널 — 경계 간격, 상태 이름 / 상태 메뉴·팝오버 ⬜(실제 앱 필요)
- ⬜ 채널 헤더 아이콘들 + 검색 결과 팝업 + 고정 메시지 팝업 + 알림 설정
- ⬜ 연결 배너 / 동기화 안내 (ConnectionBanner, RoomSyncNotice)
- ⬜ 모바일 폭(방 정보 패널 MobileRoomInfoPanel, 사이드바 열림)

## 채팅
- ⬜ 메시지 행(일반 / 연속 / 답장 / 수정됨 / 시스템 / 이벤트 행)
- ⬜ 메시지 메뉴(답장·고정·수정·삭제) + 수정/삭제 창 🔶(닫기 버튼만 수정됨)
- ⬜ 입력창(빈 상태, 입력 중, 답장 모드, 첨부 트레이 🔶, 업로드 한도)
- ⬜ 멘션 선택 / 명령어 메뉴 / 이모지 선택
- 🔶 위임 확인 카드 / 초대 링크 카드 / 입력 중 표시 / 업로드 카드
- ⬜ 투표 카드(VotePollCard)
- ⬜ 제공자 요청 메시지(ProviderRequestMessage)
- ⬜ 환영 화면(로비 / 사용자 채널)
- ⬜ 사이드챗(SideChatDock)

## 멤버
- 🔶 멤버 목록(사람 + 에이전트 묶음) — 연결선 수정됨
- 🔶 멤버 우클릭 메뉴 — 32px 행 표준
- ⬜ 프로필 팝업(사람 클릭)
- 🔶 에이전트 상세 창 — 실행/중지, 생각 표시, 사용량
- ⬜ 에이전트 상세 — 설정(모델·추론·권한), 페르소나, 프로필 편집
- 🔶 내보내기 확인 — 제목·버튼 규격

## 에이전트 추가
- 🔶 제공자 선택 그리드
- ⬜ 제공자별 설정 카드(Codex / Claude Code / OpenCode / Ollama / DeepSeek / OpenRouter / Custom API)
- ⬜ 로그인·설치·업데이트 안내, 모델 선택·새로고침, 작업 폴더 선택
- ⬜ 내 컴퓨터용 생성 창(OwnComputerCreateModal)

## 초대
- 🔶 방 초대 — 사람(주인/친구 방/외부 접속 열림), AI, 내 기기
- ⬜ 저장한 친구 선택, AI 친구 초대 카드, 커넥터 초대 카드

## 설정
- ✅ 사용자 설정 — 계정(Google/게스트/로그아웃 상태)
- ✅ 사용자 설정 — 프로필
- 🔶 사용자 설정 — 복구 코드, 기기(상대 시간, 버튼 40)
- 🔶 방 설정 — 실측 틀 적용, Fable 1차 지적 반영(세로선·베타 배지·행 테두리)
- ⬜ 방 설정 — 동기화 오류 상태, 업로드 중/실패
- ⬜ 이미지 자르기 창(ImageCropDialog)
- ⬜ 계정 탈퇴 진행 창(단계별) / Google 재확인 팝업
- ⬜ 서버 백업 카드 / 서버 복구 카드 / 로컬 데이터 선택
- ⬜ 내 컴퓨터(관리) 화면 + 런타임 재시작

## 친구
- 🔶 친구 목록 / 불러오기 실패 / 비어 있음 — Fable 지적 반영
- ⬜ 친구 추가·편집 창, 삭제 확인 / 🔶 행 메뉴
- 🔶 친구 기능 없음 안내

## 방 상태
- 🔶 연결 중 / 연결 안 됨 / 한도 소진 대기 / 내보내짐 — 카드 제거·줄바꿈 수정
- 🔶 방 만들기 / 채널 만들기 / 방 나가기 / 방 삭제 / 업로드 한도 / 투표 만들기 — 대화상자 표준(480·20·40·X) 통일

## 플러그인
- ⬜ RimWorld 플러그인 화면

## 공통 표준(실측 기반, 적용 완료)
- 대화상자: 너비 480, 여백 24, 제목 20/700, 회색 X, 버튼 40·최소 96, 보조 버튼 테두리 없는 회색
- 설정: 모달 인셋 40, 메뉴 254(항목 36, 아이콘 20), 상단 바 48, 본문 696 가운데, 섹션 제목 24, 라벨 16
- 메뉴: 행 32, 글자 14/500, 회색 호버
- 입력칸: 40, 포커스는 테두리 색(바깥 링 없음)
- 체크·라디오: 브랜드 색
- 오류 문구: 개발자용 원문·경로·ID는 화면에 내보내지 않음

## Fable 2차 지적 처리 (2026-10-20)
- 반영: 짧은 기록 바닥 정렬·환영 "!", 이 컴퓨터 통일, 공식 안내 링크색, 저장 96, 응답 속도 상자 제거(이름=켜는 것, 스위치 40×24), 바로 실행 문구, 열기 96·연필 호버 노출, 라디오 테두리 제거(실측), 뒤로 링크색, 멤버 메뉴 아이콘 정렬·음소거/추방하기/차단하기, 친구 찾기 입력형 28
- 근거 있는 유지: 추론 강도 low 등 영문 = 9cb7cdfb에서 제공자 표기로 일부러 바꿈 / "Low model" = 테스트 데이터 / 유저 패널 아바타 = 실측 32(Fable 캡처는 옛 빌드) / 열 너비 = 사용자가 조절 가능, 오른쪽 패널은 사이드챗과 공유라 기본 300 / 작성창 여백 = 디스코드 실측 8·9와 같음 / 로그인 카드 32·버튼 44 = 디스코드 로그인 카드 값
