기존 등록을 변경해야 하면 사용자에게 설명하고, 실행 승인은 해당 AI의 정상 절차를 따르세요.

실행 파일이 없다면 임의 프로그램을 내려받거나 실행하지 말고 사용자에게 설치/위치를 요청하세요.
