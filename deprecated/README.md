# Deprecated source

Files in this directory are historical reference only. They are outside every
Cargo source root and have no module, feature, test, runtime, or fallback
connection.

The Antigravity transcript, transcript-correlated prompt, and terminal-screen
permission parser are the retired turn path previously used to infer session
identity and completion. AgentsAssemble does not compile or execute them;
the user excluded managed Antigravity sessions on 2026-09-07. The subsequently
retired native driver, PTY/ConPTY transport, workspace hooks, and private terminal
helper are preserved in `antigravity-native/` without changes or build connections.
Antigravity's retained product path is an externally launched CLI joining by a Room
Connector invitation, with no app-owned CLI lifecycle. That path belongs to the
external-admission owner, not to these retired files.
