# Deprecated source

Files in this directory are historical reference only. They are outside every
Cargo source root and have no module, feature, test, runtime, or fallback
connection.

The Antigravity transcript, transcript-correlated prompt, and terminal-screen
permission parser are the retired turn path previously used to infer session
identity and completion. AgentsAssemble does not compile or execute them;
Antigravity remains visibly unavailable until its native boundary supplies an
exact attachment and completion receipt. The separate PTY/ConPTY process custody
and managed workspace-hook mechanisms remain in the provider crate.
